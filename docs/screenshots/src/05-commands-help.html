Frontline Advisor — /fla commands (chat)
Slash commands
Responses appear as [Frontline Advisor] in chat (and dump details also go to /xllog).
CommandExample chat line
/fla(toggles the advisor window)
/fla on[Frontline Advisor] Advisor notices ON.
/fla off[Frontline Advisor] Advisor notices OFF.
/fla team auto[Frontline Advisor] Your team set to auto (advice is phrased in absolute terms).
/fla map Shatter[Frontline Advisor] Map forced to The Fields of Glory (Shatter) (win at 1,600).
/fla dump[Frontline Advisor] dump: IsPvP=… dutyId=… ok=… scores=[…] map=…
/fla test[Frontline Advisor] Test notice fired (a sample lead change).
/fla config(opens Frontline Advisor — Settings)
Aliases: /fla team me, /fla cfg, /fla settings. Unknown verbs print the help line from the handler.
